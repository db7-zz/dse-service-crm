# v0.2.0｜S1 任务监督闭环

## 版本摘要

`v0.2.0` 建立从学生建档、启用服务、任务生成和分配，到管家执行、逾期暴露及管理员
介入的完整纵向闭环。

## 主要能力

- 固定八阶段 SOP 的草稿、校验、发布、停用和历史版本只读；
- 启用学生服务时基于已发布 SOP 一次生成阶段与任务快照；
- 允许未分配任务存在，并由管理员后续批量分配；
- 管家开始任务、更新进度、延期报备和完成任务；
- 管理员通过监督看板筛选任务、改期、转派、取消和处理逾期提醒；
- 实时逾期判断、每小时扫描、提醒 episode 和自动解决；
- 关键写操作的幂等、乐观锁、任务时间线和审计日志。

## 规则调整

- 统一使用“管理员端”，`ERIC_MANAGER` 的 S1 职责并入 `ADMINISTRATOR`；
- 学生建档后即可启用服务，管家和规划老师可后续分配；
- 任务完成时限最小单位为小时；
- 更换默认管家不自动转派既有任务；
- 阶段实例只组织和筛选任务，不设置状态或自动推进。

## 不包含范围

本版本不包含独立通知中心、数据导出、完整学生资料、规划老师任务权限、任务附件和阶段
自动推进。
