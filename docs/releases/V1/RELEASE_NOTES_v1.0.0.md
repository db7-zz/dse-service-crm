# DSE升学服务CRM v1.0.0发布说明

发布日期：2026-08-04

## 发布结论

本版本将S0至S5能力按总PRD统一收口，形成可完整演示的服务过程管理系统。历史阶段规格继续保留，但后续产品开发与缺陷判断只以总PRD为准。

## 主要能力

- 关系型权限覆盖管理员、管家、规划老师、专项老师和学生/家长。
- 固定八阶段SOP生成任务快照，阻塞任务终态自动推进服务进度。
- 管家任务支持进度、结果、凭证、延期、不适用、逾期和全过程时间线。
- 管理员可监督、改期、转派、取消、重开、交接人员并查看结构化审计。
- 学生档案覆盖成绩、目标、风险、团队、资料、申请和服务状态。
- 资料支持多版本上传、审核、缺失补交计划、催收任务和归档记录。
- 香港直申/JUPAS申请支持状态时间线及补件、面试、Offer联动任务。
- 问题反馈支持上下文补充、管理员回复、专项任务、解决、关闭和重开。
- 独立学生端展示资料、对外进度、申请、确认与消息，不泄露内部追责。
- 站内消息覆盖任务、资料、阶段、申请和问题关键事件，并使用唯一键去重。

## 数据库变更

迁移 `20260804000100_v1_product_completion` 只新增V1.0枚举值、学生字段、业务表、索引、外键、权限和基础资料类型，不删除历史表、字段或业务记录。执行前仍必须备份。

## 升级步骤

1. 停止应用写入并创建数据库备份。
2. 更新代码并执行 `pnpm install --frozen-lockfile`。
3. 执行 `pnpm db:generate` 和 `pnpm db:migrate:deploy`。
4. 根据环境决定是否执行开发种子；生产不得执行开发种子。
5. 执行健康检查、管理员登录、门户登录和V1验收清单。
6. 启动应用并观察API错误、迁移状态、磁盘空间与通知扫描日志。

## 兼容与限制

- 文件存储默认使用受控本地目录；生产应挂载持久化、多副本卷或替换为对象存储。
- 第三方病毒扫描、飞书自动归档、短信、邮件和微信通知不在V1.0范围；上传格式、大小和访问权限在CRM内强制校验。
- 总PRD标记为“需确认”的审批、家长独立关系、绩效和复杂流程设计器未被擅自扩展。
