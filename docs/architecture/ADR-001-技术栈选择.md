# ADR-001：技术栈与部署基线

**状态：** Accepted  
**日期：** 2026-07-28

## 决策

- pnpm 11与Turborepo管理TypeScript单仓库。
- Web使用Next.js 16 App Router、React 19和Ant Design 6。
- API使用NestJS 11、Express 5和OpenAPI。
- 数据库使用PostgreSQL 18和Prisma 7。
- 本地及首版部署使用Docker Compose，Caddy提供同源反向代理。
- 文件存储面向S3兼容接口设计，S0不部署存储服务。

## 原因

前后端统一TypeScript可以复用角色、权限和错误码；独立API便于权限、安全审计和后续任务
计算；PostgreSQL适合关系型业务与审计数据；单机Compose符合首版成本和运维能力。

## 约束

- Node主版本固定为24 LTS。
- OpenAPI是对外接口契约，前端客户端由其生成。
- 数据库变更只能通过迁移。
- 生产密钥通过环境注入，不写入镜像和仓库。
- 扩容到多实例前必须把进程内限流迁移到共享存储。
