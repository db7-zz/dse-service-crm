# ADR-002：用户名密码与数据库会话

**状态：** Accepted  
**日期：** 2026-07-28

## 决策

- 密码使用Argon2id哈希，不保存或记录明文密码。
- 登录生成高熵不透明Token，数据库只保存SHA-256摘要。
- 浏览器使用 `HttpOnly`、`SameSite=Lax` Cookie；生产环境强制 `Secure`。
- 会话最长8小时，空闲2小时；退出、停用账号和角色敏感变更撤销相关会话。
- 15分钟内连续5次失败时锁定15分钟。
- 变更请求同时校验CSRF Token和Origin。

## 错误与审计

无论账号是否存在，错误凭据统一返回 `AUTH_INVALID_CREDENTIALS`。登录成功、登录失败、锁定、
退出、会话过期和停用拦截均记录审计事件，但日志不得包含密码、Cookie或会话Token。

## 后续扩展

OIDC、企业SSO、短信、找回密码和双因素认证不在S0范围。未来接入外部身份时保留本地用户和
角色关系作为授权主体。
