## 2. 已验证纵向流程

1. 管理员维护、校验并发布固定八阶段 SOP；
2. 管理员新建学生，在未分配负责人的情况下启用服务；
3. 系统以已发布 SOP 快照一次生成八个阶段及全部任务；
4. 管理员批量分配未分配任务；
5. 管家开始任务、更新进度、提交延期报备并完成任务；
6. 系统实时识别逾期并生成唯一提醒；
7. 管理员处理提醒、改期、转派或取消任务；
8. 提醒在任务恢复正常、完成或取消后解决，再次逾期生成新 episode；
9. 关键操作在任务时间线和审计日志中可追溯。

## 4. 页面与权限

- 管理员端：学生管理、SOP 版本、监督管理看板、任务详情和审计入口可用；
- 管家端：仅展示“我的任务”及本人任务的最小学生信息；
- 规划老师及其他基础角色无 S1 任务操作入口；
- 监督列表展示任务、学生、阶段、负责人、状态、截止时间、实时逾期时长、最新延期、
  最后更新时间和提醒状态；
- 统计卡片与任务列表复用筛选口径，支持点击应用或取消对应筛选；
- 页面采用经确认的文字 UI 规范，不依赖 Figma 文件或连接器。
