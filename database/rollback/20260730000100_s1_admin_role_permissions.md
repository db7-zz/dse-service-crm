# S1 管理员角色归并与权限基线回滚说明

该迁移新增 S1 权限，向管理员和管家授予各自权限，并将有效的
`ERIC_MANAGER` 用户角色关系归并到 `ADMINISTRATOR`。迁移保留
`ERIC_MANAGER` 角色记录、已过期用户角色关系和历史审计日志。

生产环境不提供自动回滚脚本。角色归并后无法仅凭当前关系安全判断用户原本是否同时拥有
管理员角色，自动撤销可能误删合法权限。

如必须回滚：

1. 停止 Web、API 和后台任务写入，记录数据库恢复点；
2. 导出受影响用户的 `user_roles`、`role_permissions` 和相关 `audit_logs`；
3. 由管理员逐个确认需要恢复的历史业务负责人账号；
4. 仅对已确认账号重新启用 `ERIC_MANAGER` 关系，并判断是否应保留其管理员关系；
5. 恢复 S0 的角色权限映射和应用版本；
6. 验证账号登录、菜单、接口权限和审计日志后再恢复流量。

不得删除或改写迁移前后已经产生的审计日志。新增权限定义可以保留为未分配记录，避免物理
删除带来的引用风险。
